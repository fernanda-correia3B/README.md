# Analisador de Texto em Python

Este é um projeto prático desenvolvido em Python que funciona como um analisador de strings. O script recebe um texto digitado pelo usuário e exibe estatísticas básicas, além de uma transformação textual.

## 🚀 Funcionalidades

O programa analisa a entrada do usuário e entrega três resultados automáticos:
* **Contagem de Caracteres:** Calcula o tamanho total do texto inserido, incluindo espaços.
* **Contagem de Palavras:** Identifica e conta quantas palavras existem na frase de forma dinâmica.
* **Inversão de Texto:** Exibe todo o texto digitado de trás para frente.

## 🛠️ Tecnologias Utilizadas

* **Python 3.x:** Linguagem de programação base.
* **Manipulação de Strings:** Funções nativas como `.split()`, `len()` e f-strings para formatação.

## 📋 Como Executar o Projeto

Para rodar este script em seu computador, siga os passos abaixo:

1. Certifique-se de ter o **Python 3** instalado em sua máquina.
2. Baixe o arquivo `script.py` deste repositório.
3. Abra o terminal ou prompt de comando na pasta onde o arquivo foi salvo.
4. Execute o seguinte comando:
   ```bash
   python script.py
   ```
5. Digite a frase desejada quando o programa solicitar e pressione `Enter`.
